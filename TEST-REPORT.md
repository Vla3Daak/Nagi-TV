# Nagi TV v0.2.0 — отчёт о проверках

Тестовое обновление, versionCode 2. Не является подтверждением готовности к ежедневному использованию.

## Добавлено

- Независимые источники заставки и фона меню.
- Wallhaven: официальный API автоподборки аниме-пейзажей SFW, 16:9, от 3840×2160.
- Alpha Coders: выбранные пользователем прямые ссылки JPG/PNG/WebP. Каталог открывается отдельно; автоматического поиска нет.
- Zerochan: официальный API отдельных карточек с ником пользователя в User-Agent. По выбранным страницам загружаются оригиналы; поддержаны и прямые ссылки. API списка при проверке вернул HTTP 500 и некорректный JSON, случайная подборка не реализована.
- Смена фона меню: выключено / 5 / 15 / 30 минут; ручная перезагрузка; встроенный фон при ошибке.
- Арты только в RAM. Ручные URL, ник и настройки сохраняются локально.
- Публичное значение ника пустое. Персональная сборка получает ник из приватного файла, не включённого в GitHub или архив исходников.

## Проверено

- Чистая компиляция Java, Android API 30; minSdk 29 / targetSdk 30.
- Пакет `ru.vladaak.nagitv`, версия 0.2.0, versionCode 2.
- `apksigner verify`: подпись действительна и сертификат совпадает с 0.1.0. Это необходимое условие обновления без удаления, но не end-to-end тест установки.
- 87 автоматических assertions: 37 прежних политик + 50 проверок источников, доменов, прямых ссылок/страниц Zerochan, имени пользователя, SFW-фильтра и размеров.
- Java HTTPS-загрузчик скачал арт Wallhaven; декодирование Pillow подтвердило JPEG 6237×3508.
- Java HTTPS-загрузчик скачал оригинал Alpha Coders; декодирование Pillow подтвердило JPEG 3840×2160.
- Java API-запрос отдельной карточки Zerochan с разрешённым пользователем ником: корректный ответ с полями оригинала, размера и тегов. Автоматическая выдача списка недоступна; ошибки не обходились.
- Личный ник отсутствует во всех подготовленных публичных файлах и архиве исходников.
- Транспортные `.b64` и приватные данные не упакованы как публичные Android-ресурсы. В личном APK присутствует только ник API, не ключ подписи и не пароль ключа.

## Не проверено

- Установка, запуск, Android BitmapFactory, физический пульт, Home и плавность на Xiaomi TV Box.
- Полный runtime-сценарий фона/заставки и обновление установленного APK.
- Все сторонние изображения: доступность, фактический размер и содержание проверяются при каждой загрузке. SFW не является гарантией пригодности для детей.
- GitHub Release не опубликован; APK передаётся отдельно в чате. Прежние ограничения подключения на публикацию не изменялись.

## Проверка на приставке

1. Установить поверх 0.1.0, не удаляя приложение; сначала открыть как обычное приложение, не менять Home.
2. Оформление → Источник фона меню → Wallhaven. Дождаться фона. Проверить затемнение и ручную перезагрузку.
3. Заставки → выбрать отдельный источник → Предпросмотр. Проверить смену кадров и выход стрелкой.
4. Alpha Coders: добавить прямую ссылку на оригинал 4K, не страницу; проверить в меню и заставке отдельно.
5. Zerochan: проверить ник, добавить страницу выбранного горизонтального арта 4K; дождаться загрузки оригинала через API.
6. Подать неправильный URL/арт меньше 4K, отключить интернет: в меню должен остаться встроенный фон, заставка должна позволять выйти.
7. Открыть другое приложение и вернуться: загрузка и таймеры фона не должны продолжать работу поверх него.
8. Проверить сохранение настроек и избранного после перезапуска, затем при желании назначить Home по README.
