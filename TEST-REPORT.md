# Nagi TV v0.2.1 — отчёт о проверках

Тестовое обновление, versionCode 3. Запуск на физической приставке не проверен.

## Новое

Zerochan принимает одну ссылку на каталог. Каталог по умолчанию: `https://www.zerochan.net/Desktop+Wallpaper?s=id`. Для меню и заставки отдельные настройки. Работает официальный XML/RSS endpoint; JSON-выдача списка при проверке вернула 500, HTML не парсится. Оригиналы получаются через API отдельных карточек, не берутся из превью RSS. Ручной режим сохранён.

Загружается одна RSS-страница (при проверке 100 записей), из неё отбирается до 50 записей 4K с горизонтальной ориентацией и без ряда нежелательных тегов. При проверке осталось 23 подходящие записи. Кадры перемешиваются, после прохода список обновляется. Полный архив автоматически не обходится. Фильтр тегов не гарантирует SFW.

## Проверено

- Чистая компиляция и подпись APK; версия 0.2.1, versionCode 3, прежний пакет и сертификат.
- 126 assertions: 37 политик, 50 источников, 39 каталога/XML. Проверены canonical URL, домены и параметры, 4K/ориентация, дубликаты, фильтр тегов, лимит 50 записей, запрет DTD/ENTITY и сторонних ссылок.
- Java-загрузчик с разрешённым пользователем ником получил рабочий RSS каталога, разобрал 23 подходящие записи и запросил карточку первого арта.
- Java-загрузчик скачал оригинал из этой карточки; декодирование Pillow подтвердило JPEG 7680×4320. Превью 600 px не использовано.
- Встроенный публичный ник пустой. Персональный ник есть только в локальной конфигурации/личном APK, не в публичных исходниках и архиве.
- Сетевые ограничения и RAM-only режим сохранены. Ручные URL, URL каталога, ник и настройки сохраняются локально; сами арты на диск приложения не пишутся.

## Не проверено

- Установка/обновление на Xiaomi, Android XML-парсер и BitmapFactory в runtime, физический пульт, Home, интервалы и плавность.
- Доступность и содержание всех изображений, длительная работа и обновление RSS в реальном времени.
- GitHub Release пока не опубликован, APK передаётся в чате.

## Как проверить

1. Установить поверх 0.2.0 без удаления; сначала открыть как обычное приложение.
2. Настройки → Оформление → Источник фона меню → Zerochan.
3. Настроить источник → Режим → Каталог. Проверить URL Desktop Wallpaper и ник API; при необходимости «Загрузить другой фон».
4. Отдельно Заставки → Источник → Zerochan → Настроить источник → Режим → Каталог → Предпросмотр.
5. Проверить смену и выход стрелкой, отсутствие работы поверх другого приложения, встроенный фон при ошибке сети.
6. Проверить переключение обратно на ручной список и сохранение избранного/настроек.

Права на арты остаются у авторов; они не включаются в APK и не публикуются в репозитории.
