# Nagi TV v0.1.0 — отчёт о проверках

Первая тестовая сборка. Это не подтверждение готовности для ежедневного использования.

## Выполнено

- Компиляция Java и упаковка Android APK для minSdk 29 / targetSdk 30.
- Чистая повторная сборка: транспортные `.b64` исключены из Android-ресурсов; WAV/JPEG/PNG восстановлены.
- `apksigner verify`: подпись APK Scheme v3 действительна; RSA 3072.
- 37 assertions в `tests/PolicyTest.java`: формат репозитория, ограничения HTTPS, версии, адреса APK и размеры 4K.
- Две опубликованные ссылки на заставки скачаны по HTTPS и декодированы как JPEG 3840×2160.
- Ручной просмотр исходников: картинки читаются в память, дискового HTTP-кэша нет; обновления проходят проверку пакета, versionCode и сертификата, установка через системное подтверждение.

SHA-256 итогового APK: `60d915d7bf85f199911691f10097671db2ca893ed314acc526a83ba45d173a84`.
SHA-256 сертификата: `1c1deac5b1bff3102b3950fae5b191405f39f7ffcbb31639973b5183290f3b00`.

## Не выполнено

- Runtime-тест APK: программный Android TV 11 эмулятор загрузился, но ADB остался offline/unauthorized. Установка, запуск и скриншоты приложения не подтверждены.
- Физический Xiaomi TV Box, кнопка Home, D-pad/удержание OK, звук, выход из заставки, плавность и энергопотребление.
- Полный сценарий обновления с v0.1.0 на следующую подписанную версию.
- GitHub Release не опубликован: MCP не предоставляет загрузку release assets; создание workflow и Git Trees отклонено GitHub (403). Отдельные исходники и арты опубликованы через Contents API.

## Проверка на приставке

1. Установить и открыть Nagi TV как обычное приложение, не меняя Home.
2. Проверить переходы Главная → Приложения → Настройки, запуск приложений, избранное, скрытие/восстановление и порядок после перезапуска.
3. Проверить D-pad, OK, долгое OK, Назад и отключение звуков/анимаций.
4. Настройки → Заставки → Предпросмотр: дождаться изображения и смены; выйти стрелкой. Отключить интернет и проверить отсутствие зависания.
5. Запустить фильм в другом приложении: заставка Nagi TV не должна открываться поверх него.
6. Только после этих проверок назначить Home; заранее сохранить компонент штатного лаунчера по README.
