# Nagi TV · Atmosphere

Независимый лаунчер для Android TV с управлением с пульта, спокойным интерфейсом, оригинальными тихими звуками и онлайн-заставкой с аниме-пейзажами и персонажами. Вдохновлён tvOS, не связан с Apple.

**Версия 0.2.0, versionCode 2 — тестовая сборка; запуск на устройстве пока не проверен.** Целевое устройство: Xiaomi TV Box с Android TV 11; minSdk 29 (Android 10). Сборка универсальная, без нативных библиотек.

## Установка

1. Пока первый GitHub Release не опубликован, используйте APK, выданный в чате. После публикации скачивайте `Nagi-TV-v0.2.0.apk` в разделе **Releases**.
2. Установите APK на приставку, разрешив установку выбранному файловому менеджеру/загрузчику.
3. Сначала откройте Nagi TV как обычное приложение и проверьте пульт, приложения и настройки.
4. В Nagi TV: **Настройки → Основные → Открывать по кнопке Home**. Если прошивка предлагает выбор — назначьте Nagi TV.
5. Если системного выбора нет, используйте ADB-инструкцию ниже. Штатный лаунчер не удаляется и не отключается.

### Home через ADB — с возможностью возврата

Перед изменением сохраните вывод команды, это компонент исходного домашнего экрана:

```sh
adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

После установки и проверки приложения:

```sh
adb shell pm set-home-activity ru.vladaak.nagitv/.MainActivity
adb shell input keyevent KEYCODE_HOME
```

Возврат: `adb shell pm set-home-activity СОХРАНЁННЫЙ_КОМПОНЕНТ`, подставив полный компонент из первой команды. Команды могут быть ограничены производителем. Не удаляйте, не отключайте и не меняйте разрешения системного лаунчера ради установки.

## Управление

- Стрелки: перемещение, OK: открыть.
- Удержание OK / Menu: добавить в избранное, изменить порядок, скрыть, сведения.
- Назад: возврат к главному экрану; внутри деталей настроек — к меню.
- В списке приложений: вниз после второго ряда — следующая страница.
- Home: главный экран после назначения в системе.
- Звуки и анимации отключаются в настройках; громкость звуков по умолчанию 20 %.

## Источники артов и фон меню · новое в 0.2.0

Меню и заставка имеют независимый выбор источника и отдельные списки прямых ссылок.

| Источник | Что работает | Нужна настройка |
| --- | --- | --- |
| Wallhaven | Автоподборка аниме-пейзажей через официальный API: SFW, 16:9, от 3840×2160 | Ключ не нужен |
| Alpha Coders | Загрузка выбранных пользователем JPG/PNG/WebP с доменов alphacoders.com | Ввести прямые ссылки на файлы, по одной на строку |
| Zerochan | Официальный API карточек: получение оригиналов по выбранным страницам; также прямые JPG/PNG/WebP | Указать ник и ссылки на страницы/файлы, по одной на строку |
| Nagi — онлайн-подборка | Исходный screensavers.json или личный JSON-манифест | Необязательно изменить URL JSON |
| Встроенный фон | Офлайн-фон Atmosphere | Доступен для меню |

**Случайная автоматическая подборка есть только у Wallhaven.** Alpha Coders работает по прямым ссылкам: прежний адрес API при проверке вернул 404. У Zerochan работает официальный API отдельных карточек с ником в User-Agent, но endpoint списка артов при проверке вернул HTTP 500 / некорректный JSON. Поэтому Zerochan загружает оригиналы по выбранным страницам, а случайный поиск не реализован. Обход требований, парсинг каталогов и чужие API-ключи не используются. Запросы карточек Zerochan ограничены одним разом в 1.25 секунды на процесс; имя пользователя не отправляется при скачивании изображения или в другие API.

### Как включить

- **Фон меню:** Настройки → Оформление → Источник фона меню. По умолчанию остаётся встроенный фон.
- **Заставка:** Настройки → Заставки → Источник заставки. По умолчанию сохранена исходная подборка Nagi.
- **Alpha Coders:** выберите источник → Настроить источник → Открыть каталог. Выберите арт, откройте оригинальное изображение и скопируйте **его прямой HTTPS-адрес**, затем Настроить источник → Ввести ссылки. Ссылка на веб-страницу Alpha Coders не принимается.
- **Zerochan:** выберите источник → Настроить источник → Изменить ник. Нужен только ник аккаунта, пароль и cookies не используются. Затем Страницы / ссылки: добавьте URL вида `https://www.zerochan.net/1234567` (номер выбранного вами арта) или прямые ссылки на изображения. Ник можно изменить в любой момент. До 50 ссылок на источник, по одной на строку; списки меню и заставки независимы.
- В публичных ресурсах ник пустой. Личная сборка может получить ник из `private/zerochan-username.txt` на этапе сборки; этот файл и персонализированные ресурсы в GitHub не публикуются. Ник, включённый в APK, технически можно извлечь из APK: это идентификатор аккаунта, не пароль. Введённый в настройках ник хранится локально и используется в запросах к API Zerochan.
- При желании используйте браузер на компьютере/телефоне и клавиатуру приложения-пульта для ввода ссылок на приставке.
- **Смена фона:** выключена по умолчанию; интервалы 5/15/30 минут. «Загрузить другой фон» немедленно перезапрашивает выбранный источник. Без автосмены арт остаётся в текущем процессе; после его завершения загружается заново, у Wallhaven это может быть другой арт.
- Фон масштабируется с заполнением экрана и обрезкой краёв. Затемнение настраивается отдельно. При ошибке загрузки меню использует встроенный фон, статус ошибки виден в разделе Оформление. Повтор — кнопкой загрузки или при следующем возвращении в приложение.
- Оба режима проверяют фактический размер от 3840×2160, горизонтальную ориентацию, предел 8192 px по каждой стороне и 24 MiB на файл. GIF/AVIF и изображения меньшего размера в ручных списках не поддерживаются.
- Изображения и автоматическая выдача — только RAM, без дискового кэша. **Введённые вручную URL, ник Zerochan и настройки сохраняются локально**. Отдельный RAM-кадр меню может оставаться в памяти, пока работает заставка. При переходе в другое приложение загрузка/таймер фона отменяются.
- SFW Wallhaven не является гарантией пригодности для детей. В ручные списки добавляйте самостоятельно проверенные изображения. Арты не включаются в APK и не перепубликуются в репозитории; соблюдайте права авторов и правила источников.
- Нативная детализация 4K и доступность файлов не гарантируются самим размером картинки. Сторонние ссылки могут перестать работать.

## Заставка

- Работает только пока Nagi TV находится на экране, по умолчанию через 5 минут бездействия. Не создаёт системную заставку и не запускается поверх фильма в другом приложении.
- Арты загружаются по HTTPS из выбранного источника; **картинки не сохраняются на накопитель**, дисковый HTTP-кэш отключён. В RAM находятся текущий и переходный кадры, а при онлайн-фоне — также кадр меню. Ручные списки URL сохраняются как настройки.
- Смена через 30 секунд по умолчанию, мягкое растворение и медленное приближение; без звука. Часы можно отключить.
- Любая навигационная кнопка возвращает в лаунчер. Системные кнопки обрабатывает Android.
- Нужен интернет. При ошибке загрузки отображаются часы/сообщение, а не локальная копия арта; загрузка повторяется.
- Стартовая подборка: **два оригинальных ИИ-арта**, персонажи в пейзаже. Файлы 3840×2160 получены увеличением генерации 1376×768; **это не исходная детализация 4K**. Реальное разрешение вывода интерфейса задаёт Android TV/телевизор, не размер файла.
- В `wallpapers/*.jpg.b64` хранится текстовое представление JPEG; оно декодируется в RAM. Можно использовать обычные JPEG/PNG: в JSON указать `encoding: "binary"`. Проверяется фактический размер от 3840×2160, горизонтальная ориентация, предел 8192 пикселя по каждой стороне, лимит загрузки 24 MiB.
- Стартовые файлы передают около 0.75–0.78 MB на смену (примерно 90–95 MB/час при 30 сек), без учёта служебного трафика. Выбор интервала до 2 минут уменьшает расход.

## Обновление приложения

**Настройки → Обновления → Проверить обновления.** Репозиторий по умолчанию: `Vla3Daak/Nagi-TV`.

Используется официальный HTTPS API `releases/latest`: только опубликованные, не draft и не prerelease релизы. Тег `vMAJOR.MINOR.PATCH`, APK `Nagi-TV-<версия>.apk`. Изменение адреса репозитория доступно в настройках. Приватные репозитории/токены в этой версии не поддерживаются.

Перед установкой проверяются расположение APK в выбранном репозитории, размер, SHA-256 (если GitHub отдаёт digest), имя пакета, возрастающий versionCode и совпадение сертификата с установленным приложением. Установка только с системным подтверждением и разрешением устанавливать из этого источника; тихой установки нет. APK обновления временно сохраняется в приватной папке приложения и удаляется отдельной кнопкой — требование «без хранения» относится к заставкам, не к установочному пакету.

## Сборка

Java 8 source, Android API 30, Build Tools 35, Eclipse ECJ 3.40.0. Без Gradle и сторонних Android-библиотек. `build.sh` использует `TOOLS`, `ANDROID_BUILD_TOOLS`, `ANDROID_JAR`, `ECJ_JAR`. Бинарные ресурсы из репозитория восстанавливаются скриптом `tools/materialize.py`.

Ключ релиза (`private/release.jks`, alias `nagitv`) и `private/signing.env` хранятся **в отдельном приватном комплекте**, никогда в GitHub. Для совместимых обновлений необходим тот же ключ. `build.sh` выдаёт подписанный APK и проверяет подпись. Не коммитьте ключ, пароль или приватный архив.

## Приватность и ограничения

Нет рекламы, аналитики, root и сервиса специальных возможностей. Запросы выполняются к GitHub и источникам из выбранной подборки; этим серверам виден IP-адрес. Избранное и настройки локальные. Резервное копирование Android отключено.

Стабильные 60 кадров/с, вывод 4K, поведение Home, звук и физический пульт должны быть проверены на конкретной приставке. Эмулятор не заменяет такую приёмку. См. `TEST-REPORT.md`.
