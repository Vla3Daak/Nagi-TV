# Nagi TV

Лаунчер для Android TV с атмосферным интерфейсом, управлением с пульта, тихими звуками и онлайн-заставкой.

Первая версия находится в подготовке и проверке. APK, исходники и инструкции будут добавлены после сборки. Ключ подписи хранится отдельно и не публикуется.

Целевое устройство: Xiaomi TV Box, Android TV 11. Проект не связан с Apple.
